Methodology & sources

Scores are pass@1 percentages compiled from public model reports, EvalPlus results, and the BigCodeBench leaderboard data where available. They are directional, not a promise of identical performance across runtimes, prompts, or quantization levels.

Scores are shown only for the laptop-sized open models in the roster; closed API and frontier-scale reference rows are intentionally excluded.

Parameter counts are approximate. "Local fit" is a practical guide based on model size and typical 4-bit loading—not a hardware guarantee. The 14B "max spec" tier assumes 24GB+ unified memory or VRAM.

The Local eval column is HumanEval+ pass@1 measured by our own self-evaluated runs on this machine (plain chatml, greedy decoding), using the official EvalPlus evaluator. It is a directional single-run reference — useful for sanity-checking vendor-reported numbers, which can be a few points optimistic — not a nightly-refreshed source. Most models show "—" until they are run locally. A HumanEval+ cell marked † (and greyed) is a published score in conflict with our local run (≥5 points lower than our measurement) — treat it as unconfirmed and check the Local eval column. A subscore reading "pass@1 · verified" marks a published score our local run reproduced within 5 points; it is corroborated, not proven — our run is a single greedy sample on one machine.

Where this data already lives online:

  • EvalPlus leaderboard ↗ — HumanEval+ pass@1 for most models on this page
  • OpenAI HumanEval ↗ — the original 164-problem base set that HumanEval+'s edge-case tests extend
  • BigCodeBench ↗ — 1,140 practical library-based tasks; the BigCodeBench column shows Full-set pass@1 (instruct lens, complete for base models), with the Hard set in the detail panel. Data refreshed from the bigcode/bigcodebench-results ↗ datasets (Apache-2.0).
  • Hugging Face Open LLM Leaderboard (archived) ↗ — historical HumanEval results for open models
  • Artificial Analysis ↗ — independent aggregation that tracks HumanEval scores; their on-device mobile benchmarks ↗ measure real-world generation speed for many of the same small models
